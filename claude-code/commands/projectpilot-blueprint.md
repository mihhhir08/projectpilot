# ProjectPilot Blueprint

Turn this rough idea into a clean build blueprint before writing code.

Use this structure:

- Product Goal
- Target User
- Core Workflows
- Must-Haves
- Non-Goals
- Architecture
- Data Model
- UI/UX Notes
- Implementation Order
- Acceptance Criteria
- QA Plan
- Claude Code Implementation Prompt

Ask at most three blocking questions if needed. Otherwise make reasonable assumptions and proceed.
