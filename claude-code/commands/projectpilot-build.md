# ProjectPilot Clean Build

Implement the requested change using ProjectPilot quality rules.

Requirements:

- Read the repo before editing.
- Follow existing architecture and naming.
- Keep modules focused and readable.
- Avoid unrelated refactors.
- Add tests proportional to risk.
- Run the relevant verification commands.
- Finish with changed files, verification results, and remaining risks.

If the request is ambiguous, resolve safe details yourself and ask only for blocking decisions.
