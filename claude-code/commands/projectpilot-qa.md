# ProjectPilot QA Before Ship

Run a pre-ship quality pass.

Check:

- Changed files and risky files
- Build/test/lint/typecheck commands
- Primary user flows
- Empty/error states
- README or docs accuracy
- Secrets, local artifacts, generated noise

Return:

- Status: Ready or Needs Fixes
- Verification run
- Issues found
- Fixes made or recommended
- Release/PR summary
