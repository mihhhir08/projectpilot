# Idea To Blueprint Prompt

Use ProjectPilot to turn this rough idea into a clean software blueprint.

Input:

```txt
<paste idea here>
```

Output:

- Product Goal
- Target User
- Core Workflows
- Must-Haves
- Non-Goals
- Architecture
- Data Model
- UI/UX Notes
- Implementation Order
- Acceptance Criteria
- QA Plan
- Claude Code Prompt
