# UX Quality Pass

Use this skill when the user wants the project to feel polished, not merely functional.

## Review Areas

- First-run experience: can a new user succeed quickly?
- Information hierarchy: is the most important thing visible first?
- Copy: concise, specific, and confidence-building.
- Empty states: helpful without being noisy.
- Loading states: clear enough for slow operations.
- Error states: problem plus next action.
- Accessibility: labels, contrast, keyboard flow, semantic structure.
- Responsive behavior: mobile and desktop layouts both work.
- CLI UX: useful help, concise output, predictable exit codes.
- README UX: fast pitch, install, quickstart, demo, contribution path.

## Output Format

- Top 3 UX Wins: what already works.
- Top 3 UX Issues: ordered by user impact.
- Suggested Fixes: concrete changes.
- Polished Copy: replacement text for confusing labels or docs.
- QA Checks: how to verify the UX after changes.

Prefer specific edits over generic advice.
